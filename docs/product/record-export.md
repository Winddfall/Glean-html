# 成果打包，一个 JSON 带走

研究到阶段性收尾时，不用一条条复制。选择全部目标或指定目标，导出为 JSON，就能把记录交给其他工具继续处理。

## 全带走，或挑着带走

- **选择范围**：导出全部目标，或只导出指定目标。
- **标准格式**：输出 `.json` 文件，便于程序处理和长期保存。
- **衔接本地工作流**：文件可交给拾知配套 skill，用于本地归档、入库和生成报告。

## 从点击到文件落地

1. 点击 `导出记录`。
2. 选择 `全部目标` 或 `指定目标`。
3. 确认导出。
4. 在浏览器下载位置找到生成的 JSON 文件。

## 按目标分批，文件名留日期

如果你会定期整理研究资料，可以按目标分批导出。文件名建议保留日期，后续和本地数据库记录对照时更省心。

## 关于格式与命名

- 导出格式为 JSON。
- 命名为 `glean-export*.json`
