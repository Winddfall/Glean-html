# 一个气泡，一张会更新的路线图

ToDo list 不是一张越写越长的清单。拾知会根据已有记录分析各项目进展，更新任务，并给出下一步建议；你只需要跟着指引，就能完成一场像样的研究。

## 建议收在气泡里

- **消息气泡承载建议**：初始折叠，不抢走页面空间；展开即可查看当前建议。
- **自动更新任务**：AI 根据已有记录判断项目进展，更新 ToDo list。
- **给出下一步**：不只是列任务，还会提示接下来值得做什么。
- **搜索直达**：复制下一步关键词，或通过关联网址一键跳转搜索。

## 展开、复制、直达

1. 展开拾知面板中的消息气泡。
2. 查看当前建议和更新后的 ToDo list。
3. 复制下一步要搜索的关键词。
4. 点击 `搜索`，跳转到当前目标配置的关联网址搜索结果页。

## 给搜索按钮钉个家

在拾知面板底部填一个裸域名，`搜索` 按钮就有了默认的去处。

1. 在拾知面板底部找到关联网址设置。
2. 填入裸域名，例如 `zhihu.com`、`juejin.cn`、`csdn.net`、`read.douban.com`、`medium.com` 或维基百科域名。
3. 保存后，该地址成为 `搜索` 按钮的默认跳转目标。
4. 点击 `搜索`，拾知会自动识别域名并直达搜索结果页。

![todo2](/images/product/todo2.png)

## 每个目标，配一个搜索源

给不同目标配置不同搜索源：技术调查指向 `juejin.cn` 或 `csdn.net`，观点梳理指向知乎，长文阅读指向 Medium 或豆瓣阅读。路线和资料源对上了，研究会顺很多。

## 建议的来历与依赖

- 面板底部填写的是裸域名，不需要带 `https://` 或完整搜索 URL。
- AI 建议基于已记录和分析的内容生成；记录不足时，建议可能偏泛。
