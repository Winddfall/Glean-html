# 工作有档案，摸鱼进池塘

不用手动收藏、复制标题或截图归档。开启工作模式后，你打开的网页会被自动记录，随后交给 AI 分析并归入相关目标。

## 工作归工作，摸鱼进池塘

- **自动记录网页信息**：开启工作模式后，打开网页即产生记录。

- **分清工作与摸鱼**：与目标相关的记录进入工作视图，无关网页则沉入“摸鱼池塘”。

- **专注提醒**：工作时就应该专注，被无关网页吸引走会被记录进摸鱼分类。

- **看见今天的状态**：摸鱼模式只展示摸鱼池塘，并统计今天摸鱼了多少次。

## 开个模式，继续浏览

两种模式决定你看到什么，浏览本身照旧。

### 工作模式

1. 开启 `工作模式`。
2. 正常浏览网页，拾知自动记录打开的网页信息。
3. 在面板中同时查看工作目标和摸鱼池塘下的记录。
4. 访问无关网页会被记录进摸鱼分类。

### 摸鱼模式

1. 切换到 `摸鱼模式`。
2. 面板只展示摸鱼池塘中的记录。
3. 查看今天摸鱼的次数，判断该不该把标签页关掉。

## 把摸鱼当观察日记

把“专注”当作实验镜：不用苛责自己，先观察哪类网页最容易把你带走。连续几天看摸鱼分类，往往比临时戒断更有效。
