# 选中，右键，带去本地继续问

看到一段值得追问的内容，不用复制、切窗口、再重新交代上下文。选中网页文字后右键，就能把内容直接带进本地 [DeepSeek Harness](https://www.deepseek.com/harness/) 继续提问。

## 一段文字，一趟直达车

**选中即带上下文**：把网页中选中的文字传给 DeepSeek Harness。

**右键直达**：通过浏览器右键菜单发起。

**继续对话**：在 DeepSeek Harness 中围绕这段内容继续提问。

## 选中、右键、继续问

1. 在网页中选中要追问的文字。
2. 右键打开菜单。
3. 点击 `问问 Deepseek Harness`。
4. 在 DeepSeek Harness 中继续提问。

![ask dsh](/images/product/ask-dsh.gif)

## 选区越准，回答越稳

先选出核心段落，再发起提问。上下文太长时，问题容易被资料淹没；短而准的选区更容易得到清晰回答。

## 它带走的是你选的文字

- 需要本地 DeepSeek Harness 可用。
- 传递的是你选中的文字，而非整个网页内容。

## 问答发生在本机

问答发生在本地 DeepSeek Harness 中。拾知只把你选中的文字带过去，后续对话由 DeepSeek Harness 按其自身机制处理。
