# 一句话，就是一棵任务树

需求不用写得很正式。你把目标丢给拾知，AI 会把它拆解成最多 3 级任务，让下一步从“不知道从哪儿开始”变成“先做这一件”。

## 从一句话，长出三层枝桠

- **随手输入，自动拆解**：把一句话目标交给 AI，生成层级清晰的任务结构。
- **最多 3 级**：保留主干、分支和可执行动作，避免任务树长得没边。
- **拖拽排序**：各级目标都可以自由调整顺序，并带有真实物理反馈，让整理任务像移动实物一样顺手。

![需求拆解](/images/product/require.png)

## 拖一拖，枝桠就位

1. 输入你的需求或目标。
2. 等 AI 完成拆解，查看生成的任务层级。
3. 按住要调整的任务，拖到合适位置后松手。
4. 继续补充或调整其他目标，顺序会按你排列后的结构展示。
