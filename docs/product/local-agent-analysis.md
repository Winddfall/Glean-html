# 记录出了浏览器，住进本地知识库

拾知可以不只是浏览器里的助手。下载[Glean-archive skill](https://github.com/SkillRatLab/research-pilot.git) 后，本地 Agent 能接收导出的 JSON，按分类归档、写入 SQLite，并在你需要时生成深度报告。

## 归档、入库、随时出报告

- **归档**：按 JSON 中的分类结构，将记录放入本地 `~/.glean/archive/`。
- **入库**：同步写入 SQLite 数据库，便于后续查询和报告生成。
- **报告**：根据你指定的目标或分类，读取相关记录并生成结构化深度报告。
- **识别拾知文件**：当你发送 `glean-export*.json` 时，skill 会知道这是拾知浏览器扩展导出的记录。

## 三条触发暗号

满足以下任一情况时，可以把任务交给本地 Agent：

- 你发送了拾知导出的记录文件 `glean-export*.json`；
- 你要求整理或归档浏览器记录；
- 你要求基于已归档记录生成报告。

## 导出、投喂、等报告

1. 在拾知中导出记录 JSON 文件。
2. 按产品提示下载配套 skill，并安装到你的本地 Agent。
3. 把导出的 JSON 发送给本地 Agent。
4. 要求它整理、归档或生成报告。
5. 查看本地目录或 SQLite 数据库中的结果。

## 产物去哪儿了

- **文件归档**：本地 `~/.glean/archive/`
- **数据库**：本机 SQLite 数据库
- **报告**：由本地 Agent 根据你的指令生成，具体保存位置以 Agent 输出为准

## 全程在本机

配套 skill 在本地工作：归档目录、SQLite 数据库和报告生成都在你的机器上完成。使用外部 Agent 或模型前，请确认相关工具的隐私策略。
