# 记录留在本地，源与源之间修一道墙

你的浏览记录不需要上传到云端才有价值。Tabbit 脚本妙招支持同源存储：每个源下的网站共享所有目标与记录，跨源不可见；所有存储完全保留在本机。

## 四条规矩，开箱即守

- **本地存储**：目标与记录保存在你的设备上，不进入云端仓库。
- **同源共享**：同一源下的网站共享所有目标与记录。
- **跨源隔离**：不同源之间不可见。
- **数据归属清晰**：你浏览的，就是你的。

## 同源，就是分界线

“同源”决定了数据边界。你可以把它理解为：只有在同一个来源规则下的网站，才会看到同一套目标和记录；换一个源，就是另一个互不可见的空间。

## 换个源，就是另一间房

- 跨源不可见意味着，在另一个源中不会看到当前源的目标与记录。
- 如果你发现目标或记录“消失”，先确认当前网站是否仍处于原来的源。

## 数据在你手里

存储完全本地，完全透明。清除浏览器本地数据、卸载扩展或相关脚本，可能影响记录可用性。重要成果建议定期使用 `导出记录` 保存 JSON 文件。
