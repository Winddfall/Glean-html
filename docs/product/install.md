# 安装

安装脚本妙招「拾知」之前，需要先安装 Tabbit。

## 先认识 Tabbit

Tabbit 是拾知的运行环境，也是一切脚本妙招的载体。关于 Tabbit 的一切，都可以在官网找到：[https://www.tabbit.com/](https://www.tabbit.com/)

## 脚本妙招是什么

脚本妙招是 Tabbit 浏览器的妙招（Skill）功能中的一个类型，本质上是一段可以修改网页的代码。用户可以用自然语言描述自己的需求（比如"自动屏蔽广告""修改网页样式"等），Tabbit 会自动生成对应的脚本代码。当用户点击脚本妙招时，脚本会被直接执行，对当前网页进行修改或操作，实现网页内容处理、页面展示调整或重复操作的自动化。如果想让网页恢复原样，手动刷新即可。

脚本妙招还支持设置**生效范围**，可以指定脚本只在特定网址或 Tabbit 首页上运行。在运行过程中，脚本还可以调用 Tabbit 提供的大模型服务，结合当前网页内容进行智能处理，从而扩展能力边界。

使用方式上，可以在输入框为空时输入 `/` 唤起妙招列表选择执行，也可以从右上角的灯泡面板中查找并运行。

## 安装拾知

拾知以脚本妙招的形式运行，有以下两种安装方式。

### 方式一：官方妙招广场

通过 Tabbit 的官方[妙招广场](https://skills.tabbit.com/plaza/skills?view=plaza)搜索并安装「拾知」。也可以直接点击[这里](https://web.tabbit.com/share/skill/EcrPZgXkFP)安装。

### 方式二：手动安装（GitHub）

通过 GitHub 手动安装。安装包与说明正在整理中，稍后补充。
