# 用得越久，它越懂你的路数

不用每次重新解释自己。拾知会定时更新用户画像，把它当作 AI 记忆，影响后续的分析、建议和输入补全。

## 画像在长，建议在变

- **形成 AI 记忆**：从你的目标与记录中提炼长期偏好。
- **定时更新**：画像不是一次性快照，而是随使用持续演进。
- **影响多个功能**：用于 AI 分析、ToDo 建议、输入补全等场景。

![profile](/images/product/user-profile.png)

## 照常用，画像自己长

1. 正常创建目标、浏览网页并让记录进入分析。
2. 等待用户画像按设定周期自动更新。
3. 在后续分析、建议和补全中查看是否符合你的工作方式。

## 画像的质量，看记录

- 画像质量取决于记录质量：目标越清晰，记录越相关，AI 越容易理解你的长期方向。
- 定时更新意味着变化不会立刻体现，通常需要等待下一轮刷新。
- 画像不像你？没关系，Glean 支持删除和自定义画像条目

![profile](/images/product/user-profile2.png)

## 画像留在本机

用户画像保存在本地，与浏览记录一样遵循本地存储原则。画像具体内容、存储位置和是否参与外部模型上下文，请以应用权限与设置说明为准。
