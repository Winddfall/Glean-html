# 欢迎收集

打开、浏览、忘记、再找回来——以前的查资料总是这样。拾知把这套流程换掉：目标拆成任务树，网页自动归档，AI 在后台把零散浏览整理成可以推进的研究。

下面 4 步，带你上手。

## 1. 开局

这一站叫需求拆解：你说目标，AI 拆成最多 **3 级任务**，拖一拖就是你的开工顺序。

输入你的目标或需求，等 AI 把它拆成最多 3 级任务，按住任务拖一拖，把顺序摆成你舒服的样子。

---

## 2. 浏览

开启 `工作模式` 后，浏览照旧——网页自动记录，AI 分析完就归入**相关目标**。自动记录与分析归档，在这一步合体。

被无关网页带走？它会被记进摸鱼池塘—— `专注`功能会帮你留意这一点。

---

## 3. 跟随

面板里的消息气泡，装着会根据记录更新的智能 ToDo list，还有下一步该做什么的建议。

---

## 4. 沉淀

记录导出成 JSON 后，交给本地 Agent 辅助分析：归档、入库、随时出报告。

点击 `导出记录`，选择全部或指定目标，拿到 JSON 文件。

把文件交给已安装配套 skill 的本地 Agent。

记录被归档到本地 `~/.glean/archive/`，写入 SQLite，随时可以生成深度报告。
