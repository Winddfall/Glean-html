# 写到一半，AI 递来下半句

想搜什么、想问什么，往往写到一半才清楚。Tabbit 首页的输入框提供 AI 文本建议自动补全，让表达从半句话变成完整请求。

## 接着你的思路写

**接着写**：根据你已输入的内容，生成续写建议。
**在首页完成**：入口位于 Tabbit 首页输入框。
**理解你的偏好**：结合用户画像，让建议更贴近你的表达习惯和研究方向。

## Tabbit？   Tab it！

1. 打开 Tabbit 首页。
2. 在输入框中开始输入。
3. 查看出现的补全建议。
4. **Tab** 接受建议，或继续输入直到表达完整。

![auto](/images/product/auto-complete.gif)

## 先给关键词，再让它续写

输入补全最适合处理“知道方向，但没想好措辞”的时刻。先写下关键词，再让建议帮你补全成完整问题。

## 建议不是标准答案

- 补全建议基于当前输入和用户画像生成，不保证覆盖所有可能问法。
- 用户画像会定时更新，因此建议风格可能随使用记录逐渐变化。
